dengeX Remote Pilot 2 — Windows ekranını Mac'ten izleme

1. Windows'ta yeni Pilot 2 ZIP'ini tamamen çıkartın ve dengeX Remote.exe'yi açın.
2. Cihaza bağlan > Bu bilgisayarın ekranını paylaş > Davet oluştur seçin.
3. Windows'ta görünen kodu Mac'te Davet ile ekranı izle bölümüne girin.
4. Mac'ten Bağlantı isteği gönder'e basın.
5. Windows kullanıcısı cihaz adını kontrol edip Ekranımı paylaşmayı kabul et'e basar.

Kontroller:
- Windows onay vermeden önce Mac'te Windows ekranı görünmemeli.
- Windows onayından sonra Mac'te Windows ekranı görünmeli. Windows'ta bir
  pencereyi hareket ettirerek görüntünün canlı olduğunu kontrol edin.
- Windows'taki veya Mac'teki Denemeyi bitir düğmesi görüntüyü kapatmalı.
- Windows uygulamasını kapatmak ekran paylaşımını durdurmalı.
- Yeniden deneme için yeni davet oluşturulmalı.

Bu yönde Mac ekran kaydı izni gerekmez. Mac kendi ekranını paylaşacaksa izin gerekir.
Windows ilk monitör, en fazla 1280x720; uzak klavye/fare kontrolü yoktur.

Sorun olursa uygulamada PİLOT 2 yazdığını ve iki cihazın Sunucu adresinin aynı
olduğunu kontrol edin. Eski Pilot 1 Windows uygulaması davet oluşturamaz.
Hangi adımda kaldığınızı ve görünen hata metnini iletin. Davet kodunu veya
özel ekran içeriğini hata raporlarına eklemeyin.

Windows 11 x64, WebView2 Runtime ve Media Foundation gerekir. İmzasız pilot
pakettir. TURN olmayan ağlarda görüntü bağlantısı kurulamayabilir. Gerçek
Windows ekranı/iki cihaz kabul testi henüz tamamlanmış sayılmaz.
