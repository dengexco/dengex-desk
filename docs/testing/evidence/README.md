# Yayınlanan test kanıtları

Bu dizin yerel geliştirme sırasında alınan sonuçları içerir; ayrıntılı kapsam
ve başarısız veya çalıştırılmamış kontroller `../results.md` içinde açıklanır.

Herkese açık yayın için kullanıcıya ait mutlak dosya yolları `<workspace>`,
cihaz kimliği `[cihaz kimliği çıkarıldı]`, geçici pilot adresi ise
`https://pilot.example.invalid` ile değiştirilmiştir. Bu adres çalışır bir
sunucu değildir. Sayısal test sonuçları ve başarı/başarısızlık durumları
değiştirilmemiştir. Özgün kayıtlar yerel, Git'e dahil edilmeyen arşivde tutulur.
