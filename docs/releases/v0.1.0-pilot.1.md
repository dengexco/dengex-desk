# dengeX Remote 0.1.0 Pilot 1 — Windows x64

## Hangi dosya indirilecek?

**`dengeX-Remote-Windows-x64.zip` dosyasını indirin.** ZIP'in tamamını bir
klasöre çıkartıp içindeki **`dengeX Remote.exe`** dosyasını açın. `resources`
klasörünü uygulamanın yanında tutun. **Source code (zip)** uygulama paketi değildir.

Tek dosya isteyenler için `dengeX-Remote-Windows-x64.exe` de eklenmiştir. Bu EXE
kurulum sihirbazı değildir; doğrudan uygulamayı açar. Tek başına kullanıldığında
**Cihaza bağlan → Sunucu adresi** alanına Mac'teki güncel HTTPS adresi elle girilir.

## Bağlantı

1. Windows'ta **Cihaza bağlan** bölümünü açın ve cihaz adını yazın.
2. Mac kullanıcısı **Davet oluştur** ile tek kullanımlık davet üretir.
3. Windows'ta daveti girip **Bağlantı isteği gönder** düğmesine basın.
4. Mac kullanıcısı ekran kaydı iznini açar ve gelen isteği kabul eder.

Bu sürüm yalnızca Windows'tan Mac ekranını izleme pilotudur. Windows ekranını
paylaşma veya uzak klavye/fare kontrolü içermez. Cloudflare adresi geçicidir;
Mac ve pilot sunucusu açık kalmalıdır. TURN yapılandırılmadığı için bazı ağlarda
doğrudan görüntü bağlantısı kurulamayabilir.

## Gereksinimler ve doğrulama

- Windows 11 x64 hedeflenir; Microsoft Edge WebView2 Runtime gerekir.
- İmzasız geliştirme paketidir. Güvenlik korumalarını kapatmayın.
- Windows x64 PE biçimi, ZIP bütünlüğü ve SHA-256 kontrol edilmiştir.
- Kaynak kontrolleri geçti; gerçek Windows açılışı ve iki fiziksel cihazda canlı
  görüntü kabulü henüz tamamlanmadı. Bu yayın bir **pre-release** sürümüdür.
- ZIP, public sunucu adresini içerir; davet, yönetim anahtarı veya özel cihaz
  anahtarı içermez.

`TEST-ADIMLARI.txt` deneme adımlarını, `SHA256SUMS.txt` dosya özetlerini içerir.
Proje MIT lisanslıdır; lisans ve bağımlılık bildirimleri ZIP'e eklenmiştir.
