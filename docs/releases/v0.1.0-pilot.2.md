# dengeX Remote Pilot 2 — Windows cihazına Mac'ten bağlanma

Bu sürüm, önceki pakette eksik olan **Windows'ta davet oluşturma ve Windows
ekranını Mac'ten izleme** yolunu ekler. İki bilgisayarda da Pilot 2 kullanın.

1. **`dengeX-Remote-Windows-x64.zip`** dosyasını Windows'a indirip tamamını çıkartın.
2. **`dengeX Remote.exe` → Cihaza bağlan → Davet oluştur** seçin.
3. Mac'te **Davet ile ekranı izle** bölümüne Windows'taki kodu girin.
4. Windows kullanıcısı gelen bağlantı isteğini kabul eder.

Mac yalnızca görüntü izlediği için Mac ekran kaydı izni gerekmez. Mac kendi
ekranını paylaşacaksa macOS izni gerekir. **Source code (zip)** uygulama değildir.
Tek EXE de eklenir; yanında `resources/pilot-server.json` yoksa sunucu adresi
elle girilmelidir. ZIP, bu dosyayı ve kullanım adımlarını içerir.

Windows native görüntü yolu: DXGI → NV12 → Media Foundation H.264 → WebRTC.
İlk monitör en fazla 1280×720 aktarılır; 20 fps hedefi bir performans kabulü
değildir. Windows/uygulama kapanması, yerel iptal ve yetki süresinin bitişi
gönderimi kapatır. Döndürülmüş monitör, imleç birleştirme, RDP/güvenli masaüstü
ve uzak klavye/fare bu pilotun dışındadır.

Sunucu `DX_PILOT_GUEST_HOSTS=1` ile misafir oda oluşturmayı açar. Misafir yalnızca
kendi odasını oluşturur; davet tek kullanımlıktır, ekran paylaşımı host onayı
ve imzalı kısa süreli grant gerektirir. Yönetim anahtarı EXE'ye eklenmez. Kabul
bütçesi sunucu genelinde 6 davet/dakika ve en fazla 8 açık odadır; kullanıcı
hesabı veya doğrulanmış teknisyen kimliği yerine geçmez.

Windows 11 x64, WebView2 ve Media Foundation gerekir. Windows N için Media
Feature Pack gerekebilir. İmzasız geliştirme paketi, **pre-release** sürümüdür.
Gerçek Windows ekranı ve iki fiziksel cihazda canlı görüntü kabulü henüz yoktur.
Cloudflare adresi geçicidir; sunucunun çalıştığı Mac açık kalmalıdır. TURN
olmadığı için bazı ağlarda görüntü bağlantısı kurulamayabilir.

`SHA256SUMS.txt`, `TEST-ADIMLARI.txt` ve lisans bildirimleri sürüme eklenir.
