Windows ve macOS için kendi sunucunuzda çalışan, onaylı ekran paylaşımı betası.

- Windows: **dengeX-Remote-Windows-x64.zip** dosyasını tamamen çıkarın; **dengeX Remote.exe**, **dengex_desktop.dll** ve **resources** birlikte kalmalı.
- Apple Silicon Mac: **dengeX-Remote-macOS-arm64.zip**.
- Intel Mac: **dengeX-Remote-macOS-x86_64.zip**.
- İki cihazda aynı HTTPS dengeX sunucu adresini girin. Paketlerde ortak sunucu veya geçici tünel adresi yoktur. [Sunucu kurulumu](https://github.com/dengexco/dengex-desk/blob/main/docs/self-hosting.md) · [Kullanım kılavuzu](https://github.com/dengexco/dengex-desk/blob/main/docs/quickstart.md).

WebRTC 0.21.1, güncel TLS/sertifika bileşenleri ve JavaScript güvenlik düzeltmeleri dahildir.

Yeni ana ekran doğrudan davet oluşturma ve bağlantı akışını açar. Sunucu kontrolü, adresin hatırlanması, sekme değiştirirken oturumun korunması, HTTPS kurulumu, onay sonrası süreli TURN/UDP kimlik bilgileri ve zorunlu relay modu eklendi. Paketler kaynak koddan GitHub Actions ile üretilir; Windows DLL yüklemesi ve API/transport/güvenlik testleri yayın öncesi çalıştırılır. ZIP özetleri SHA256SUMS.txt dosyasındadır.

**Sınırlar:** yalnızca görüntüleme; uzaktan klavye/fare, ses, dosya aktarımı, kalıcı cihaz ID'si ve katılımsız erişim yoktur. TURN/TCP ve TURN/TLS desteklenmez. Paketler Authenticode/Apple Developer ID ile imzalı değildir. macOS ekran kaydı izni, Windows WebView2 gerekir. Gerçek iki cihazdaki görüntü ve donanım uyumluluğu kullanıcı kabul testi gerektirir; CI derlemesi bu testin yerine geçmez.
